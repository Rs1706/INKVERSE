REST Architecture

Server Endpoints

Все данные лендинга управляются через открытый REST API сервер. Вы можете отправлять прямые запросы через cURL, Postman или внешние приложения.

Метод Эндпоинт Описание Формат ответа
GET /api/comics Список всех выпусков комиксов, лайки, теги и страницы JSON: { success, count, data: [...] }
GET /api/comics/:id Детальный синопсис и данные выпуска по ID (например: 01) JSON: { success, data: { synopsis, ... } }
POST /api/comics/:id/like Инкремент лайка выбранного комикса в базе данных JSON: { success, likes: 143 }
GET /api/weather Погода в Ташкенте с серверным 60-сек кэшем (Open-Meteo) JSON: { city, temperature, humidity, ... }
POST /api/contact Отправка заявки / сюжета от читателя с присвоением ID билета JSON: { success, ticketId: "INK-9482" }
GET /api/stats Суммарная статистика вселенной (лайки, читатели, выпуски) JSON: { success, data: { activeReaders, ... } }
GET /api/health Проверка работоспособности и аптайма сервера JSON: { status: "ok", uptime: "..." }
